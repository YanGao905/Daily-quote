# Daily Quote - 每日一句

每天展示一句来自经典日剧的台词，包含日文原文、中文翻译、相关图片和出处。

## 功能特点

- ✨ 每天自动显示不同的日剧台词
- 🇯🇵 日文原文 + 中文翻译
- 🖼️ 配图展示
- 📺 显示剧名和年份
- 📅 显示当前日期和星期
- 🎨 简洁优雅的设计（基于Figma设计）
- 📝 **可视化管理界面** - 轻松添加、编辑、删除台词
- 🖼️ **图片上传** - 直接上传图片，自动保存
- 💾 **数据导入导出** - 备份和分享您的台词库
- 📱 **滑动切换** - 上下滑动查看前后几天的台词
- ✨ **视差效果** - 滑动时文字和图片有不同的移动速度

## 使用方法

### 查看台词
1. 打开 `index.html` 查看今日台词
2. **上下滑动** 或使用 **方向键** 查看前后几天
3. 点击 **滚轮** 或使用 **触摸滑动**（移动端）
4. 点击右侧 **箭头按钮** 切换

### 管理台词 ⭐ 新功能
1. 点击右上角的 **⚙️ 齿轮图标** 进入管理页面
2. 或直接打开 `admin.html`

#### 添加台词
1. 填写日文台词、中文翻译
2. 输入剧名和年份
3. **上传图片**（支持 PNG、JPG、SVG）
4. 点击"添加台词"按钮

#### 编辑台词
- 点击台词卡片上的"✏️ 编辑"按钮
- 修改后重新提交

#### 删除台词
- 单条删除：点击"🗑️ 删除"按钮
- 批量删除：点击"删除全部"按钮

#### 导入导出
- **导出**：备份所有台词为 JSON 文件
- **导入**：从 JSON 文件恢复或合并台词

## 操作指南

### 滑动切换
- **向上滑动/滚轮向上** → 查看前一天
- **向下滑动/滚轮向下** → 查看后一天
- **键盘 ↑** → 前一天
- **键盘 ↓** → 后一天
- **点击箭头按钮** → 快速切换

### 数据存储
- 所有台词保存在浏览器 **localStorage** 中
- 即使关闭浏览器也不会丢失
- 建议定期导出备份

## 图片要求

- **格式**：PNG、JPG、SVG
- **建议尺寸**：324x496 像素（竖版）
- **背景**：透明或纯色背景效果最佳
- **文件大小**：建议小于 2MB（大图片会自动转为 base64）
